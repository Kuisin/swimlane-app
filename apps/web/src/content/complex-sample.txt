[customer: Place order] <start>
label: Submit order;
desc: ```
Customer submits the cart. Includes **shipping address**
and an _encrypted payment token_.
```;
props: reqdoc;

[frontend: Validate form] <gate>
desc: ```
Check required fields and reject malformed input
before it reaches the API.
```;
props: reqdoc, auditlog;

if (form valid?) is (valid) than #green
[api: Accept request]
desc: ```
Authenticate the caller and enqueue the order
for fulfillment.
```;
props: auditlog;
[worker: Reserve stock] <job>
desc: ```
Place a soft hold on inventory while the
shipment is being prepared.
```;

if (stock available?) is (in stock) than #blue
[db: Decrement inventory]
desc: ```
Atomically reduce the on-hand count for each
line item in the order.
```;
[worker: Create shipment] <job>
desc: ```
Allocate a carrier and generate the shipping label.
```;
props: receipt;
elseif (backorder) than #orange
[worker: Queue backorder] <job>
[customer: Notify delay]
skip;
else
[customer: Refund]
[db: Log refund]
endif

[api: Confirm order]
desc: ```
Persist the final order state and emit the
confirmation event to downstream consumers.
```;
elseif (recoverable) than #orange
[frontend: Show retry prompt]
[customer: Resubmit]
[loop]
else
[frontend: Show fatal error]
skip;
[api: Emit failure metric]
skip;
endif

[customer: Receive confirmation] <terminal>
label: Confirmed;
desc: ```
Customer sees the confirmation screen with the
order summary and estimated delivery date.
```;

if (wants receipt?) is (yes) than #purple
[api: Render receipt]
desc: ```
Build the PDF receipt from the order and
payment records.
```;
props: receipt;
[customer: Download receipt]
skip;
endif
